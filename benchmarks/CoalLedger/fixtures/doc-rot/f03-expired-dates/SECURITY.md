# Security Policy

## Supported Versions

| Version | Supported | End of Life |
|---------|-----------|-------------|
| 4.x | Yes | — |
| 3.x | Yes | December 2025 |
| 2.x | Security fixes only | June 2024 |
| 1.x | No | January 2023 |

Last security audit: October 2023 by TrailOfBits.

Next scheduled audit: Q1 2025.

## Reporting a Vulnerability

Please report vulnerabilities to security@example.com. We aim to respond within 48 hours.

Our bug bounty program runs through HackerOne (launched March 2024). See https://hackerone.com/example for details.

## Disclosure Policy

We follow a 90-day coordinated disclosure policy, effective since January 2024.
