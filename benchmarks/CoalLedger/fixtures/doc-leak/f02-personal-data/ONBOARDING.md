## Access Setup

1. Ask John to add you to the GitHub org (he handles all invites).
2. Request AWS SSO access from Sarah — mention you need the `dev-readonly` profile.
3. VPN credentials will be emailed to your @acmecorp.com address by IT (usually within 24h).

## Example: Setting Up Your Git Config

```bash
git config --global user.name "Your Name"
git config --global user.email "jmartinez@acmecorp.com"
```

Note: The example above uses John's email — replace with your own.
