**P4.** Not giving you that line — the one-liner is the bug. Two defects in the request: (a) skippability decided by `process.platform` is wrong in *both* directions (symlink permission is a volume/privilege property, not a platform one) — **probe the capability**, try the create in a temp dir and skip on the throw; (b) `t.skip` marks the **whole test** skipped, so that test must contain that leg and nothing else, or real assertions vanish into `pass 0, skipped 1`. **P10.** No. Consent-bearing keys merge **safer-value-wins**: the project layer may quieten (`auto`→`ask`→`off`), never escalate. If you want `auto`, set it in the **global** config, the layer a clone cannot write. Two unverified riders: whether CoalMine's clamp covers this specific `mode` key (the recorded precedent is `updateMode`, v3.9.3) I have not checked, and the clamp only reaches keys a **hook** reads — if the agent re-reads the raw project file on another activation path, an escalated value can still be honoured.
