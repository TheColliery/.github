# Accessibility

This is the accessibility statement for TheColliery's repositories. GitHub shows it as the **Accessibility** tab on a repository that has no `ACCESSIBILITY.md` of its own; a repository that ships its own file overrides this one.

## What it covers

The documentation in the repository: its README and the other Markdown files, as GitHub renders them and, where the repository is published there, on the project's GitBook site.

## What we do

- Every image in a document carries alt text, and link text states where the link goes, never "click here" or a bare URL. This is the rule in our [documentation pattern](https://github.com/TheColliery/.github/blob/main/DOC-PATTERN.md), which follows W3C WCAG.
- Headings keep a correct hierarchy, with no skipped levels.

## What we do not claim

No WCAG conformance level is claimed for these repositories. This statement says what we do, not that an audit has been passed.

## Report a barrier

Open an issue in the repository ([how to get help](https://github.com/TheColliery/.github/blob/main/.github/SUPPORT.md)) and say what you could not read or reach. One maintainer decides what is fixed ([governance](https://github.com/TheColliery/.github/blob/main/.github/GOVERNANCE.md)). A security problem goes to the private channel in [SECURITY.md](https://github.com/TheColliery/.github/blob/main/.github/SECURITY.md) instead.
