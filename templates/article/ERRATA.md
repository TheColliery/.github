# ERRATA.md—defects found in published versions

A released version is frozen: whoever wrote a conformance record against version `1.0.0` has to be able to
open `1.0.0` and find the document they conformed to. A defect found in a released version is corrected in
the NEXT version, and recorded here.

**Entries are never removed. Not even rejected ones.** A rejected erratum keeps its evidence and the
reasoning that rejected it, so the next reader does not spend an afternoon re-reporting something already
settled.

**Being listed here is not being fixed.** Nothing in this file changes the released text; corrections ship
in the next version. To report something, see [`CONTRIBUTING.md`](CONTRIBUTING.md).

**Every entry pins the version it was found in and quotes the text.** The quoted text is the locator; a
line number on its own rots at the next edit.

Status is one of: **reported** · **verified** · **rejected** · **held for the next version**.
